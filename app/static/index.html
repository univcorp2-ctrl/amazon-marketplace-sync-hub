AIエージェントで本番まで進める手順

1
Amazon Seller / SP-API準備
Seller Central → Developer登録 → SP-APIアプリ登録 → 必要Role付与 → 自分のSellerアカウントでアプリ認可 → LWA Client ID / Secret / Refresh Token取得。
2
Shopee Seller / Open Platform準備
対象国のSeller Shopを有効化 → Open PlatformでPartner/App作成 → Shop Authorization → Partner ID / Key / Shop ID / Access Token取得 → 出品カテゴリーとLogisticsを確認。
3
Secretを本番バックエンドへ設定
秘密情報はGitHubやPagesに貼らずSecret Storeへ。API管理キー、限定CORS、永続DBも設定します。
4
1商品だけプレビュー
この画面でジャンルを指定 → 禁止リスト判定 → 価格差確認 → 1件だけ出品。Shopee側の商品ID・カテゴリー・送料・画像・価格を人が確認します。
5
少量自動化を有効化
BULK_LISTING_ENABLED=true。最初は1回5件 / 1日20件以下。403・429・連続エラーが出たら自動停止のまま原因確認します。
6
在庫・価格同期
永続DBへShopee item_idを保存し、定期同期。Amazon販売不可・禁止判定変更時はShopee在庫0へ落とします。
7
定期監査
Shopee禁止品ルール、Seller Health、APIエラー率、為替・手数料・送料を確認。上限を増やすのは正常運用を確認してから。
